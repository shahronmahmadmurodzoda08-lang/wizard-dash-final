# Wizard Dash: Arcane Neon — Android

Android-only build. The repository uses one GitHub Actions workflow.

## Build APK

1. Upload the extracted repository contents to a clean GitHub repository.
2. Open **Actions**.
3. Run **Build Wizard Dash Android**.
4. Download the artifact **wizard-dash-debug-apk**.
5. Install `app-debug.apk` on Android.

The workflow uses Gradle 8.9.2 with Android Gradle Plugin 8.7.3 and Java 17.
