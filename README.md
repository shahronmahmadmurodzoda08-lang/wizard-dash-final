# Wizard Dash Ultimate Android

A portrait Android RPG game built as a local HTML5 game inside an Android WebView.

## Included gameplay

- 20 worlds
- 100 missions per world
- 2,000 total mission slots
- Sequential world and mission unlocking
- Boss mission at mission 100 of every world
- Real-time touch battle
- Enemy scaling
- Player leveling and XP
- Gold and Diamonds
- Shop with weapons, armor, skins, boots, magic, potions and tactics
- Inventory and equipment
- Permanent HP, Power, Speed, Defense, Mana and Critical upgrades
- Daily free reward wheel
- Daily reward cooldown
- Profile and avatar selection
- Achievements
- Offline save using localStorage
- Offline friend duel simulation
- Online-mode UI and room codes ready for a future multiplayer backend
- GitHub Actions debug APK build

## GitHub

Upload the extracted contents of this project to a repository root. Do not upload the ZIP as the project itself.

Then open Actions and run `Build Wizard Dash Android`.

## Important

The game itself is playable offline. Real internet multiplayer between two separate phones requires a backend/server; this package includes the online room interface but does not invent or hard-code a third-party server.
