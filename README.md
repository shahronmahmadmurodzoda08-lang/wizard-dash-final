# Wizard Dash — Full Playable Build

Landscape-first dark-fantasy action game prototype with:
- splash/loading 0–100%
- local/offline profile save
- Google/GOST/Guest entry UI
- 20 worlds × 100 missions
- sequential world and mission unlocking
- real canvas combat with W/A/S/D and touch controls
- dash, jump, strike, skill, shield and potion actions
- boss fights and rewards
- gold, diamonds, energy, XP and leveling
- shop, weapons, armor, inventory
- avatars, emotes and skills
- daily gift and luck wheel
- ranking, friends, guild, events and settings panels
- landscape PWA shell and offline caching

Open `index.html` in a browser. On Android, add the page to the home screen for fullscreen landscape behavior.
